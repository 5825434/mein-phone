# מיין פון — מערכת ניהול

דשבורד ניהול לעסק "מיין פון" (ניוד קווים, מכירת טלפונים, מלאי, ספקים) — לפי מסמך האיפיון `מיין-פון-איפיון-2.md`.

## מצב נוכחי

- שלד React + Vite + Tailwind CSS, RTL מלא, גופנים Heebo/Rubik.
- ניווט מלא בין 8 המודולים (סיידבר), כולל routing.
- **דשבורד ראשי בנוי במלואו** עם נתוני דוגמה: KPI cards, גרף מכירות חודשי, עוגת פילוח לפי קטגוריה, טבלת ניודים אחרונים.
- שאר המודולים (לקוחות, ניודים, מלאי, הזמנות, ספקים, דוחות, הגדרות) הם כרגע מסכי "בקרוב" עם הפניה לסעיף הרלוונטי באיפיון — עדיין לא ממומשים.
- **Supabase עדיין לא מחובר** — ראו `src/lib/supabaseClient.js` ו-`.env.example`. עד לחיבור, כל המסכים עובדים על נתוני דוגמה קבועים בקוד (`src/data/sampleData.js`).

## הרצה מקומית

```bash
npm install
npm run dev
```

נפתח על http://localhost:5173

## חיבור ל-Supabase (כשתהיה מוכן)

1. צור פרויקט חדש ב-[supabase.com](https://supabase.com).
2. העתק את `.env.example` ל-`.env` (הקובץ לא נכנס ל-git).
3. מלא את `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY` מתוך Project Settings → API.
4. הפעל מחדש את `npm run dev`.

## פריסה

- **אתר:** `npm run build` מייצר תיקיית `dist/` סטטית — מתאים לפריסה ב-GitHub Pages (ראו סעיף 5 באיפיון).
- **דסקטופ אופליין:** עדיין לא הוגדר (Electron/Tauri) — ראו סעיף 5.1 באיפיון לתכנון.
- הניתוב במערכת (`HashRouter`) נבחר בכוונה כדי לעבוד גם ב-GitHub Pages וגם באפליקציית דסקטופ בעתיד, בלי הגדרות שרת מיוחדות.
